# HE75 V2 TMR, internal model 3613

This `HE75 V2 TMR` catalog identity uses VID/PID 3151:5054 and **two profiles**.
It is distinct from four-profile TMR model 3883 (3151:5030). Its partial USB
backend includes normal/submode and Windows/Mac Fn maps, macros, magnetic
actuation/modes/snap, switch selection, main and side lighting, five RGB picture
banks, OS options, calibration and schema-7 backup/restore. Hardware behavior
remains unverified.

Mac loader `6f31d22e.js` selects `660ec711.js`, directly inheriting `623d2d52.js`.
Windows loader `d915b681.js` selects `16167605.js`, inheriting `17dc9c62.js`.
The children declare only three 512-byte matrices; their bytes match across
both supplied installers:

| Matrix | SHA-256 |
| --- | --- |
| Normal | `b001e55a9612ef07886dd6b2ee4ad01e29dfe4279a520d9d31382bc0ec8b58ef` |
| Windows Fn | `44a0574915ab5c07f06a50e4f579d89b019bfb0506724ec44615dc1da51b8ed5` |
| Mac Fn | `e4f599fbbd372dae750edd0c1ab99a0ae8e0cb154b3e7186bec38958348175ee` |

Both catalogs advertise four switch types: 云玉磁轴 (93), 泰山轴 (86),
磁玉pro (2), 万磁王 (5). There is no special display alias or knob metadata.
The knob restrictions of models 3518/3883 are therefore not applied to 3613.

Side layout `ei` has wave, neon, solid and off effects; wave/neon speed is
0–4. Ordinary color/rainbow flags are 7/8, and neon forces flag 8.
See [HE75 side-light protocol](he75-v2.md). Debounce is not exposed.

Travel is 0.1–3.3 mm in 0.01 mm steps, subject to coarser firmware wire
precision. Other magnetic settings use shared firmware-dependent bounds.
Normal Bluetooth and dongle sleep accept 60–3600 seconds, and deep Bluetooth
accepts 600–3600 seconds. The hidden fourth timer remains unchanged.
[Recovery](he-recovery.md) preserves raw configuration, including values outside
ordinary edit limits, with exact model and firmware checks.

```text
epomaker --device /dev/hidrawN status
epomaker --device /dev/hidrawN profile 1
epomaker --device /dev/hidrawN switch-type 泰山轴 1
epomaker --device /dev/hidrawN sleep 120 120 1800
epomaker --device /dev/hidrawN light wave --side --speed 4
```

Evidence: Mac and Windows main catalog blocks at lines 44358–44387, their
loader tables and the child/base modules above. Independent simulated tests
cover these model gates, exact matrices, CLI dispatch, side-light packets,
calibration and complete recovery. These checks do not establish hardware parity.
